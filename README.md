# Simple Interest Calculator

## Description
A simple interest calculator that calculates
interest based on principal amount, rate of
interest, and time period.

## Formula
Simple Interest = (P × R × T) / 100

Where:
- P = Principal Amount
- R = Rate of Interest
- T = Time Period

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Enter principal amount
- Enter rate of interest
- Enter time period
- Calculate simple interest
- Display total amount
